# FABY Keeper (نسخة محلية)

الواجهة الأصلية (`index.html` + `style.css` + `app.js` + `api.js`) مع خادم وهمي في المتصفح (`mock-api.js`)
يحفظ البيانات في `localStorage`، فلا يحتاج أي backend.

- التشغيل: افتح `index.html` أو انشر المجلد كموقع ثابت (Vercel/GitHub Pages).
- لتصفير البيانات: نفّذ `MOCK_DB_RESET()` في كونسول المتصفح.
- لاحقًا يمكن حذف `mock-api.js` وربط الواجهة بـ backend حقيقي يحقق نفس مسارات `/api` المذكورة في `api.js`.
- `lite/` نسخة مبسطة مستقلة.

حدود معروفة: أسماء الدخول/كلمات المرور غير مفعّلة (مستخدم manager ثابت)، والنقل الجماعي في المستودع غير منفّذ، والبيانات على جهاز واحد فقط.
