# نظام الحقائب التدريبية – فاب لاب الأحساء

تطبيق عربي RTL لإدارة الحقائب التدريبية بدل العمل المباشر على ملفات Excel.
واجهة واحدة لتسجيل الدخول، وتظهر لكل حساب الواجهة المناسبة لصلاحيته.

## الأدوار
| الدور | القيمة في `profiles.role` | ماذا يرى ويفعل |
|---|---|---|
| موظف | `staff` | ينشئ حقائبه ويعدّلها ويرسلها للمراجعة، ويعرضها كاملة |
| مديرة المشاريع | `project_manager` | ترى كل الحقائب، تعرضها كاملة (قراءة فقط)، وتعتمدها أو تعيدها للتعديل مع ملاحظات |
| المدير | `admin` | كل صلاحيات مديرة المشاريع + تعديل أي حقيبة + إدارة صلاحيات المستخدمين |

الحساب الجديد يُنشأ من Supabase ← Authentication ← Users، ويظهر في صفحة «المستخدمون» (للمدير) بعد أول دخول ليحدد دوره. الافتراضي موظف.

## ما يغطيه النظام (القوالب الثلاثة)
- **قالب الحقيبة**: بطاقة البرنامج، المخرجات (مع الصور المرجعية)، خطة التنفيذ، الموارد، الجاهزية، المرفقات، قائمة الاكتمال، التوقيعات والاعتماد.
- **قالب المحتوى العلمي**: المحتوى لكل يوم (13 حقلاً)، المخرج التقني المرجعي، المراجع والمصادر.
- **قالب دليل الطالب**: بيانات التنفيذ، الترحيب، التعريف، سأنفذ/سأتعلم، المخرج النهائي، الجدول، التقييم، ما أحتاج إحضاره، التعليمات، فريق التواصل.
- الحقول المكررة بين القوالب (الاسم، المستوى، العمر، المدة، الأهداف، ماذا سنتعلم كل يوم) تُسحب تلقائياً ولا تُكتب مرتين.

## العرض والتصدير
- **عرض الحقيبة كاملة** على الموقع (ثلاثة مستندات) مع زر طباعة / حفظ PDF، وهو ما تراه مديرة المشاريع.
- **تصدير Excel** إلى قالب الحقيبة المعتمد (`assets/training-bag-template.xlsx`) مع الحفاظ على تنسيقه، ويشمل الصور المرجعية وقائمة الاكتمال والاعتماد.
- حفظ تلقائي أثناء التعديل.

## إعداد قاعدة البيانات (مرة واحدة)
شغّل الملف `supabase/migrations/20261123_roles_and_extras.sql` في Supabase ← SQL Editor. يضيف:
- جدول `bag_extras` (المحتوى العلمي ودليل الطالب والصور والمرفقات والاعتماد)
- دوال الأدوار `is_admin()` و`is_manager()` وسياسات الصلاحيات الإضافية
- حماية: تغيير الدور للمدير فقط، والاعتماد/الإعادة للتعديل للإدارة فقط
- مخزن الملفات الخاص `bag-files` لصور المخرجات والمرفقات

## الملفات
- `index.html` الواجهة · `app.js` الأدوار والحفظ · `extras.js` أقسام المحتوى العلمي ودليل الطالب والرفع · `view.js` العرض والمراجعة والمستخدمون · `export.js` تصدير Excel
